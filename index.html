サービス

進出に必要な、すべてを。

初期調査から現地での実務オペレーションまで、ワンストップで対応します。

01
市場調査・参入戦略
ターゲット市場の分析、競合調査、最適な参入方法の提案。現地11年の肌感覚とデータを組み合わせた実行可能な戦略を設計します。
02
法人設立・法務対応
LLC・C-Corp等の法人設立手続き全般。信頼できる現地弁護士・会計士ネットワークを活用し、登記から各種契約まで対応します。
03
ビザ・在留資格サポート
E-2・L-1・O-1など各種ビザの申請サポート。複数の日本人スタッフのビザ申請を主導してきた実務経験をもとに支援します。
04
不動産・物件取得
事務所・店舗・倉庫など事業用不動産の調査・交渉をサポート。アラモアナセンター（Brookfield）との2年間の交渉経験を活かします。
05
採用・組織構築
現地ネットワークを活かした採用支援。7カ国以上の多国籍チームを統率してきたノウハウで、現地スタッフの採用から教育まで対応します。

アプリ開発

御社専用の業務アプリを、
一から作ります。

アメリカ進出後の現場で本当に必要なツールは、既存のアプリには存在しないことがほとんどです。多国籍スタッフ・現地の商習慣・日本語対応——すべてを踏まえた業務アプリを、実際に現場で使い続けてきた経験をもとに開発します。

💬
多言語スタッフチャット
Steak Teppei（ハワイ）導入実績
日本語・英語・中国語が混在するスタッフ間のコミュニケーションを、AIがリアルタイムで翻訳。メッセージを送ると全員が自分の言語で読める。既製品のチャットアプリでは対応できない多言語・多文化チームの課題を解決。
  • 送信と同時にAIが3言語へ自動翻訳
  • 文脈を読んだ高精度翻訳（主語・目的語を補完）
  • 画像送信・既読確認・@メンション対応
  • PIN認証でインストール不要・iPhoneのホーム画面から起動
  • 管理者パネルで発言削除・アナウンス配信が可能
PWA / Firebase / Gemini AI
📦
業者発注管理アプリ
Steak Teppei（ハワイ）導入実績
業者ごとの発注内容を管理・記録するアプリ。発注履歴の確認、定番商品のワンタップ再注文、AIによる発注文の自動生成が可能。紙やメモアプリで管理していた発注業務をデジタル化し、発注ミスや伝達漏れを防ぐ。
  • 業者別・カテゴリ別の商品管理
  • 過去の発注履歴をワンタップで確認・再利用
  • AIが発注内容を自然言語で補助
  • スマートフォン最適化・オフライン対応
  • マニュアル内蔵でスタッフへの引き継ぎが簡単
PWA / Cloudflare Worker / Gemini AI
💰
給与・チップ計算アプリ
Steak Teppei（ハワイ）導入実績
アメリカのチップ文化に対応した給与計算アプリ。勤務時間・残業・チップを自動集計し、従業員ごとの支払い額を算出。Clover POSとAPI連携し、売上データから自動でチップを取り込む。会計事務所への共有もワンクリック。
  • Clover POS（レジ）と直接API連携しチップを自動取得
  • 通常時給・残業時給（1.5倍）を自動計算
  • 従業員別・期間別のチップ履歴をグラフで可視化
  • Google Sheetsに自動保存・会計士と共有可能
  • ペイロール期間ごとの集計レポートを自動生成
PWA / Google Apps Script / Clover API
📊
月次棚卸しアプリ
Steak Teppei（ハワイ）導入実績
毎月の在庫棚卸しを効率化するアプリ。商品リストに数量を入力するだけで金額を自動計算し、Google Sheetsに保存。「牛肉の単価を変更して」と入力するだけでAIが商品マスターを自動更新。食材・飲料・備品をカテゴリ別に集計。
  • 商品名・単価・カテゴリをGoogle Sheetsで一元管理
  • 数量を入力するだけで金額・合計を自動計算
  • AIチャットで商品マスターの価格変更が自然言語で可能
  • 月次レポートをFood・Drink・Container別に自動生成
  • ダーク/ライトモード対応・iPhone最適化
